# SBRGREEN Construction Website

Public website for **SBRGREEN Construction Private Limited**, built with Create React App.

## Pages

- Home
- About
- Services
- Projects
- Gallery
- Careers
- Contact

## Run locally

```bash
cd WEBSITE
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
